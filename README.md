# ASTRATENT — шапка для Tilda

Файл `astratent-header.html` — единственный исходник шапки. Он включает HTML, CSS и JS для блока **T123** на странице **«Шапка сайта адаптив»**, которая назначается глобальной шапкой в Tilda.

## Установка
1. Открыть Tilda → «Шапка сайта адаптив» → блок T123 → «Контент».
2. **Полностью заменить** прежний код содержимым `astratent-header.html`.
3. Опубликовать шапку и все страницы. GitHub сам по себе не публикует код в Tilda.
4. Проверить /catalog, / и мобильную ширину 360 px.

## Поведение
- До 1099 px — двухстрочная версия, от 1100 px — одна строка.
- Отступы и размеры плавно меняются через clamp; ширина шапки не ограничена 1240px.
- Слоган показывается с 600 px, его шрифт адаптивный.
- Поиск передаёт запрос в Tilda Store каталог через `tfc_query[5166680601]`.
- Автозаполнение браузера отключено; собственные подсказки из недавних запросов и заранее заданных категорий точно равны ширине строки. **Это не API автоподсказок Tilda**.
- Избранное, профиль, корзина — кнопки-заглушки с диалогом «Раздел скоро появится». Реальные страницы и функции не подключены.
- Изменения в GitHub нужно переносить в T123 вручную либо организовать отдельный процесс деплоя.

## Проверка
Размеры: 320, 360, 768, 961, 1024, 1100, 1440 px. Проверить меню, поиск, запрос в URL, подсказки, закрытие диалога.

## Для Codex
Не менять ID ключа поиска и существующие URL. Править один исходник `astratent-header.html`, избегать дублирования тегов style/header/script. Не добавлять фиктивные URL или делать вид, что корзина уже работает. Сохранять доступность с клавиатуры, focus states и мобильный layout.
